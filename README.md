# Andrew Abeles Portfolio

This repository is a preserved static copy of Andrew Abeles's portfolio website, prepared for version control and optional GitHub Pages hosting.

## Preview locally

Open `index.html` in a browser. For fully reliable relative links, serve the folder with any simple local web server.

## Publish with GitHub Pages

1. Create a new GitHub repository. Private is recommended until Andrew approves publication.
2. Upload the contents of this folder to the repository root.
3. Review all pages and contact details.
4. When Andrew approves, enable GitHub Pages from the repository's main branch and root folder.

The existing ChatGPT-hosted site is not changed by this package.

## Main sections

- `index.html` — main portfolio and project navigation
- `fundraising/` — focused fundraising and donor-communications presentation
- `project_pages/` — individual project pages
- `assets/` — project PDFs, images, thumbnails, and site artwork
