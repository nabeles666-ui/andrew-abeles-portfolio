# Andrew Abeles Portfolio

This repository contains Andrew Abeles's public portfolio website, published with GitHub Pages.

## Preview locally

Open `index.html` in a browser. For fully reliable relative links, serve the folder with any simple local web server.

## Live site

- Main portfolio: https://nabeles666-ui.github.io/andrew-abeles-portfolio/
- Fundraising portfolio: https://nabeles666-ui.github.io/andrew-abeles-portfolio/fundraising/

## Main sections

- `index.html` — main portfolio and project navigation
- `fundraising/` — focused fundraising and donor-communications presentation
- `project_pages/` — individual project pages
- `assets/` — project PDFs, images, thumbnails, and site artwork
